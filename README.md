# Amira High School

Amira High School is a web-based School Management System developed using Flask, Python, SQLite, HTML, CSS, and JavaScript.

## Features

### Student Management

* Student registration
* Student login using phone number and password
* Unique student ID generation (e.g., AHM2026001)

### Announcement Management

* Admin can create announcements
* Upload announcement images
* Edit and delete announcements
* Students can view announcements

### Course Management

* Add courses
* Update courses
* Delete courses
* View available courses
* Store course information including duration, teacher, fees, and course image

### User Roles

* Admin
* Student
